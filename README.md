# Candypad QMK Userspace

Generated by [Candypad Configurator](https://candypad.app).

## 🚀 Quick Start — Compile Online (No Local Setup!)

1. **Create a new GitHub repo** and push the contents of this ZIP to it
2. GitHub Actions will **automatically compile** your firmware
3. Go to **Actions → Build QMK firmware → latest run → Artifacts**
4. Download the `.bin` file from the **Firmware** artifact (inside a .zip)
5. Flash with **QMK Toolbox** or **dfu-util** in DFU mode

### Flashing with QMK Toolbox

1. Open [QMK Toolbox](https://github.com/qmk/qmk_toolbox/releases)
2. Select the `.bin` file
3. Put your Candypad in DFU mode (hold the boot button while plugging in USB)
4. Click **Flash**

### Flashing with dfu-util

```bash
dfu-util -a 0 -d 0483:DF11 -s 0x08000000:leave -D binepad_candypad_candypad_keymap.bin
```

## 🔧 Alternative — Fork the Official Repo

1. Fork [binepad-global/qmk_userspace_binepad](https://github.com/binepad-global/qmk_userspace_binepad)
2. Replace the keymap folder at `keyboards/binepad/candypad/keymaps/` with the one from this ZIP
3. Push — GitHub Actions will compile automatically

## 💻 Local Compilation

```bash
# Install QMK CLI
python3 -m pip install qmk
qmk setup -H ~/qmk_firmware -b sr-candykeys-candypad binepad-global/qmk_firmware

# Copy keymap
cp -r keyboards/ ~/qmk_firmware/keyboards/

# Compile (outputs .bin for STM32 DFU)
qmk compile -kb binepad/candypad -km candypad_keymap

# Flash via DFU
qmk flash -kb binepad/candypad -km candypad_keymap
```
