CandyPad Keymap Editor

A visual keymap editor for the binepad CandyPad — a 19-key QMK macropad with two rotary encoders and a 128×32 OLED, built on an STM32F103. It edits QMK's keymap.json directly in your browser and can write it straight back into a local clone of your firmware repository.

Why it exists

The vendor's own web configurator cannot express modified keycodes — there is no way to put LCTL(KC_LEFT) on a key. It also shipped firmware with real defects: layers that no key could reach, and mouse keycodes assigned while the mousekey feature was switched off, so those keys compiled and silently did nothing. This editor accepts any expression valid inside QMK's LAYOUT() macro, and validates the keymap before you spend four minutes building it.

What it does

  • Assign any keycode, including nested modifiers such as LCTL(LSFT(KC_TAB)).
  • Browse the full QMK keycode table through task categories rather than QMK's internal groups.
  • Set all three rotary encoder actions per layer — counter-clockwise, press, clockwise.
  • Catch unreachable layers, keycodes whose feature is disabled, keycodes the hardware cannot do, and encoder/layer count mismatches that would otherwise fail a STATIC_ASSERT at compile time.
  • Edit the OLED brightness, timeout and custom render code that ship in config.h and oled.c.
  • Save into a local clone, download the JSON, or share a keymap as a link — no account, no token.

How to use it with your own CandyPad

  1. Fork and clone the repository.
  2. Open this page, choose Link repo… and pick your clone's root folder (Chrome or Edge).
  3. Edit keys and knobs, then Save to repo.
  4. Commit and push — GitHub Actions builds the firmware and attaches the .bin to the run.
  5. Flash it with dfu-util -d 1EAF:0003 -a 2 -R -D <firmware>.bin or QMK Toolbox. This board uses the stm32duino bootloader, not the STM32 ROM DFU.
